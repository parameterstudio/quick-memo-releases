# Quick memo 설치 파일 (배포 전용)

PARAMETER LAB 회의록과 연결되는 윈도우용 데스크톱 스티커 메모 앱 **Quick memo** 의 설치 파일을 두는 저장소입니다.

## 설치

1. 최신 설치 파일 받기: https://github.com/parameterstudio/quick-memo-releases/releases/latest/download/QuickMemo-Setup.exe
2. 받은 `QuickMemo-Setup.exe` 를 실행하면 바로 설치됩니다(윈도우 10 / 11, 64비트).
3. 설치 뒤 LAB 계정으로 로그인해 사용합니다.

## 안내

- 코드 서명이 없어 설치할 때 **'알 수 없는 게시자'** 경고가 뜰 수 있습니다. '추가 정보' → '실행'을 선택하면 설치됩니다.
- 이 저장소에는 설치 파일만 있습니다. 소스 코드는 여기에 없습니다.
